INDEPENDENT ARCHIVE / OUR MISSION

WHY OG VHS?

The format was temporary. The memories aren't.

For a while, the internet was built around six seconds at a time. Tiny loops became jokes, conversations, odd experiments, and little accidental time capsules.

OG VHS is an independent project to preserve original Vine posts before they vanish into forgotten hard drives, broken links, and out-of-date platforms.

The archive currently contains 0 verified records. The goal is accuracy over completeness: the original Vine ID is kept as the permanent identity for a clip, and captions, hashtags, and dates are included only when they're known.

No made-up quotes or fabricated posting dates. If we haven't recovered a caption, you'll see Caption not recovered. It's a work in progress, and that's part of its story.

The public archive is read-only. Source files are held separately from this site, so the collection can move to OGVHS.com or another host without losing its identity.
